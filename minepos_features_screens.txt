MinePOS - COFFEE SHOP POS
Feature & Screen List

===================================
FEATURES
===================================

Platform Fundamentals
- Windows, Android, Web - single Flutter codebase
- Thai/English switchable language
- Role-based UI ("one app, configurable role")

Core POS Modules
- Order taking with auto order numbers
- Kitchen Display System (KDS) with real-time WebSocket updates
- Payments: Cash + Thai PromptPay QR
- Thermal receipt printing (Bluetooth or USB only)
- Menu management
- Reports with CSV export
- Discounts - per-item or per-order, fixed amount or percentage

Special Features
- Optional customer-facing display
- Toggleable stock tracking per menu item
- Thermal printer support via Bluetooth or USB

Hosting & Connectivity
- Self-host on Windows PC/Desktop only (Dart Shelf HTTP/WebSocket server)
  - Android and other devices connect as clients to the desktop host
- Online/cloud mode as a switchable alternative
- mDNS discovery for automatic device connection on Wi-Fi
- Offline order buffering with auto-sync

Security
- Username/password login with bcrypt hashing
- JWT tokens with role encoded
- Staff management with force logout
- OTP-based password recovery via registered email
